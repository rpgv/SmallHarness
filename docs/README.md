# SmallHarness documentation

Start with the [README](../README.md) for installation and a first run. These pages
go into detail.

**Using it**
- [Chat](chat.md): talking with the model, commands that bring in tools and modes,
  pins, threads, rewinding, and how the context is kept small.
- [Research](research.md): the knowledge base, asking, references, attaching, notes,
  and how searching works.
- [Planner](planner.md): creating, expanding, editing and running plans.
- [Recipes](recipes.md): turning a recipe into a file section by section, and the code
  library.
- [Web interface](web.md): every tab, Relics, and how the local server is protected.
- [Commands](commands.md): the terminal modes, their commands, and one-off shell use.

**Setting it up**
- [Models](models.md): downloading, listing and deleting models, short names, context
  size, RAM and instances.
- [Engines](engines.md): LiteRT-LM (server, Python and command-line modes) and Ollama.
- [Configuration](configuration.md): `smallharness.toml`, changing settings while
  running, workspace trust, and where state is kept.
- [Tools](tools.md): the tools plan runs can call, and writing your own.

**Contributing**
- [Development](development.md): the code layout and running the tests.

                      Context
                      
      
                      Whether earlier messages reach the model. Pinned messages and answers always do; everything is
        still kept and shown either way.
                      
      
      
                      The default for every chat that was not switched on its own (the context toggle next to a
        chat's title). Off, a reply sees only the message it answers, pinned messages and its thread.
                      
      
      
                      Asking about a relic (the Ask box on the Relics page) talks in that relic's own chat, and
        each message carries its sections or the whole file. Off (the default), a reply sees only the message it
        answers, so earlier copies of the file do not fill the context.
                      
      
      
                      Off (the default), each question is answered from its excerpts and the pinned answers alone. On,
        the session's latest answers come too, as many as fit in [research].history_budget.

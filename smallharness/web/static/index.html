              Draft a plan
              
          
          
          
              One step per line: N. [tool] what to do (after: N); its details on the
            indented lines below it. A step you leave unchanged keeps its status.
              
          
              
          
              
            
            
          
              
        
              
        
              
          
              
            
            
              
          
              
            Tick a step to mark it done; untick it and the next run does it again.
            
          
              
          
                
          
                
            Expand
            
            
            
            
          
                
          
                
            Run
            
            
            
          
                
          
                Runs use the workspace tools; risky ones ask you first. They see the plan, the step's
            details and earlier results; nothing from the knowledge base.
                
          
                
        
                
      
                
    
                
  
                

  
  
                
    
                
      
                
        
                Recipes
                
        
                  
      
                  
      
                  
        
                  A recipe is turned into a file one section at a time. Separate sections with an empty
          line and describe in each what to write. Every section is written by its own model call that sees only
          that section; its only tool is risky_write_file, which you allow once.
                  
        
                  
          
          →
          
          
        
                  
        
        
                  
          
          
          
          
          
          
          
        
                  
        
                  
          Untick a section and the next Write writes it again.
          
        
                  
        
                    
        
                    
        
                    
          
                    Code library
                    
          
                    Code mode keeps each section as a snippet, one library per language. Before a section is
            written, its library is searched: a near-duplicate is reused without the model, and similar snippets are
            offered to it.
